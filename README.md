# 🗺️ IA PokeApi - Explorador de Pokémon

Uma aplicação moderna e responsiva para listar, buscar e explorar informações detalhadas sobre os Pokémon, consumindo os dados oficiais da [PokeAPI](https://pokeapi.co/).

---

## 🚀 Funcionalidades

*   **Listagem Completa:** Exibição dos Pokémon com paginação ou scroll infinito.
*   **Busca em Tempo Real:** Filtre os Pokémon pelo nome ou número da Pokédex.
*   **Cards Detalhados:** Visualização de tipos (Fogo, Água, Grama, etc.), status base (HP, Ataque, Defesa) e habilidades.
*   **Design Responsivo:** Interface adaptável para dispositivos móveis, tablets e computadores.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido utilizando as seguintes tecnologias:

*   **React** (ou React Native / Expo, dependendo da sua estrutura)
*   **TypeScript** (Garantindo tipagem estática e segurança no código)
*   **Styled Components** (Para estilização moderna e escopada)
*   **Fetch** (Para requisições HTTP na PokeAPI)
